jawaban soal: 

1. Perbedaan Diskon Per Item vs Diskon Total Transaksi

Diskon per item → diskon dihitung pada masing-masing barang.
Contoh:

Kopi Latte 20.000 diskon 10% → 18.000

Espresso 15.000 diskon 5% → 14.250

Diskon total transaksi → diskon dihitung dari total belanja.
Contoh:
Total 100.000 → diskon 10% → bayar 90.000.

Intinya:

Per item = tiap barang punya diskon sendiri.

Total transaksi = diskon sekali di akhir.

 2. Cubit untuk Logika Diskon Dinamis

Cubit membantu karena:

Logika diskon disimpan di Cubit, bukan di UI → kode lebih rapi.

Otomatis hitung ulang total ketika item ditambah, dihapus, atau jumlah berubah.

Aturan diskon fleksibel, misalnya diskon berdasarkan total atau jumlah barang.

UI auto-update setiap Cubit mengirim state baru → tidak perlu setState() manual.

Intinya: Cubit bikin perhitungan diskon jadi rapi, otomatis, dan mudah dikelola.

3. Manfaat Widget Stack untuk Tampilan Kategori

Stack berguna untuk:

Menumpuk elemen (gambar + teks + ikon) jadi tampilan lebih menarik.

Posisi bebas (pakai Positioned), misalnya teks di bawah, badge promo di pojok.

Bikin UI kategori lebih modern, mirip aplikasi marketplace.

Lebih simpel daripada nested container yang panjang.

Intinya: Stack memudahkan bikin tampilan kategori yang estetik dan profesional.
